# Contributing

Thank you for your interest in contributing to this repository.

This repository serves as a professional cybersecurity knowledge base focused on ethical hacking, penetration testing, web application security, and offensive security methodologies.

## Purpose

The goal of this repository is to document practical security techniques, laboratory exercises, technical references, and assessment methodologies using a consistent and professional documentation standard.

## Contribution Guidelines

Contributions should:

- Improve technical accuracy
- Follow industry best practices
- Maintain clear and concise documentation
- Use professional terminology
- Include references where applicable
- Respect the existing folder structure

## Documentation Standard

Each technical document should follow this structure where appropriate:

- Overview
- Objectives
- Theory
- Methodology
- Practical Assessment
- Commands
- Findings
- Mitigation
- References

## Naming Convention

Use descriptive names with hyphens.

Examples:

- SQL-Injection
- Cross-Site-Scripting
- Windows-Authentication
- Burp-Suite

Avoid:

- week1
- notes
- test
- new-folder

## References

Whenever possible, reference official documentation such as:

- OWASP
- NIST
- MITRE ATT&CK
- Microsoft Learn
- PortSwigger
- Kali Linux Documentation

## Code of Conduct

Contributors are expected to maintain respectful, professional, and constructive communication.

## Disclaimer

All contributions must relate only to authorized security testing, laboratory environments, or educational research. Do not submit content that encourages or facilitates unauthorized access to third-party systems.
