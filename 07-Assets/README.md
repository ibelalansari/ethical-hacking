# Assets

> A centralized repository of supporting media, diagrams, screenshots, and visual resources used throughout this cybersecurity portfolio.

---

## Overview

This section contains visual assets that support technical documentation, security assessments, and laboratory exercises.

Assets provide evidence for documented findings, improve technical explanations, and enhance the overall readability of the repository.

---

## Objectives

- Organize supporting visual resources
- Maintain assessment evidence
- Improve documentation quality
- Provide reusable diagrams and illustrations
- Standardize asset management across the repository

## Best Practices

- Use descriptive file names.
- Prefer PNG format for screenshots and diagrams.
- Remove or anonymize sensitive information before publishing.
- Compress large images when appropriate.
- Keep assets relevant to the associated documentation.

---

## References

Visual assets are used to support documentation and should correspond to the relevant assessment, report, or technical note within this repository.
