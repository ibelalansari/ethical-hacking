# Ethical Hacking

> Technical documentation, security assessments, practical methodologies, and hands-on exercises focused on ethical hacking and offensive security.

---

## Overview

This repository contains structured technical documentation, practical assessments, and security methodologies covering ethical hacking, web application security, reconnaissance, vulnerability analysis, and penetration testing.

The content is organized by security domain and documents practical techniques, tools, workflows, and defensive considerations.
