# Reconnaissance

> Reconnaissance is the initial phase of a security assessment that focuses on collecting information about a target to identify potential attack surfaces, exposed assets, technologies, and security weaknesses.

---

## Overview

Reconnaissance is the foundation of penetration testing and offensive security operations. The objective is to gather accurate information about a target while minimizing detection. Information collected during this phase supports attack surface mapping, vulnerability identification, and subsequent security assessments.

Reconnaissance is generally categorized into:

- Passive Reconnaissance
- Active Reconnaissance

---

## Objectives

- Identify publicly exposed assets
- Discover domains and subdomains
- Collect DNS information
- Enumerate network infrastructure
- Identify technologies and services
- Build an attack surface profile
- Reduce uncertainty before assessment

## Methodology

A typical reconnaissance workflow consists of:

1. Define assessment scope
2. Collect passive intelligence
3. Identify exposed infrastructure
4. Enumerate accessible services
5. Correlate collected information
6. Document findings
7. Validate discovered assets
